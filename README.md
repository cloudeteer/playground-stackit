# playground-stackit

[![STACKIT Confluence Shield]][STACKIT Confluence Space]

STACKIT is the cloud and DevOps platform of the Schwarz Group (known for Lidl and Kaufland), specializing in the provision of cloud services, development platforms, and other IT solutions.

The platform is aimed at companies that value European data sovereignty and offers a wide range of services for Infrastructure-as-a-Service (IaaS), Platform-as-a-Service (PaaS), and Managed Kubernetes.

This repository is used to test the provisioning of infrastructure on this platform, specifically through the creation of GitHub Actions workflows and Terraform code, but also beyond these pillars of our potential Managed Services.

For more details, visit our [STACKIT Confluence Space].
